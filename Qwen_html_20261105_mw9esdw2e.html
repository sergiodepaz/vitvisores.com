Sistemas Operativos

¿Qué es un Sistema Operativo?

Un sistema operativo es el software principal de una computadora que gestiona los recursos de hardware y proporciona servicios a los programas de aplicación. Actúa como intermediario entre el usuario y el hardware de la computadora.

Funciones Principales:

  • Gestión de memoria y procesos
  • Administración de archivos y directorios
  • Control de dispositivos de entrada/salida
  • Seguridad y protección del sistema
  • Interfaz de usuario (gráfica o línea de comandos)

Tipos de Sistemas Operativos:

  • Windows: El sistema más popular para PCs
  • macOS: Sistema exclusivo de Apple
  • Linux: Sistema de código abierto con múltiples distribuciones
  • Android/iOS: Sistemas operativos móviles

Los sistemas operativos modernos permiten la multitarea, la ejecución simultánea de múltiples programas y la gestión eficiente de los recursos del sistema.

Programación

¿Qué es un Lenguaje de Marcas?

Un lenguaje de marcas es un sistema de notación que permite etiquetar o marcar elementos en un documento para indicar su estructura, formato o significado. A diferencia de los lenguajes de programación, no realizan cálculos ni operaciones lógicas.

Lenguajes de Marcas Más Comunes:

  • HTML (HyperText Markup Language): Estándar para crear páginas web. Define la estructura del contenido mediante etiquetas como <h1>, <p>, <div>, etc.
  • XML (eXtensible Markup Language): Utilizado para almacenar y transportar datos de forma estructurada.
  • CSS (Cascading Style Sheets): Aunque no es estrictamente un lenguaje de marcas, complementa a HTML definiendo estilos y presentación.
  • JSON: Formato ligero de intercambio de datos basado en texto.

Características:

  • Sintaxis basada en etiquetas o marcadores
  • Estructura jerárquica y anidada
  • Independiente del lenguaje de programación
  • Legible tanto para humanos como máquinas
Redes

¿Qué es Internet?

Internet es una red global de redes informáticas interconectadas que utilizan protocolos de comunicación estandarizados (TCP/IP) para compartir información y recursos a nivel mundial.

Historia:

Nació en 1969 como ARPANET, un proyecto del Departamento de Defensa de EE.UU. En 1989, Tim Berners-Lee inventó la World Wide Web (WWW), revolucionando la forma en que accedemos a la información.

¿Cómo Funciona?

  • Protocolos: TCP/IP permite la comunicación entre dispositivos
  • Direcciones IP: Identifican de forma única cada dispositivo en la red
  • DNS: Traduce nombres de dominio a direcciones IP
  • Routers: Dirigen el tráfico de datos entre redes

Servicios Principales:

  • World Wide Web (páginas web)
  • Correo electrónico
  • Transferencia de archivos (FTP)
  • Mensajería instantánea
  • Streaming de video y audio
Redes

¿Qué es un Servidor?

Un servidor es un sistema informático (hardware y software) que proporciona datos, recursos o servicios a otros programas o dispositivos llamados "clientes" a través de una red.

Características:

  • Alto rendimiento: múltiples CPUs, gran RAM
  • Almacenamiento robusto con RAID
  • Conectividad de red de alta velocidad
  • Redundancia y refrigeración avanzada
  • Funcionamiento 24/7

Tipos según función:

  • 🌐 Servidor Web: Apache, Nginx - Sirven páginas web
  • 📧 Servidor de Correo: Gestionan emails
  • 🗄️ Servidor de Base de Datos: MySQL, PostgreSQL
  • Servidor DNS: Resuelven nombres de dominio
  • 🔄 Servidor Proxy: Intermediarios de red

¿Para qué sirve?

  • Almacena archivos: Guarda y entrega documentos, imágenes, videos
  • Hospeda sitios web: Alberga páginas web y las envía a los clientes que quieren acceder a ellas
Bases de Datos

SQL vs NoSQL: La Base de la Información

Las bases de datos son sistemas organizados para almacenar, gestionar y recuperar información de manera eficiente. Existen dos grandes categorías: SQL (relacionales) y NoSQL (no relacionales).

Bases de Datos SQL (Relacionales):

  • Estructura tabular con filas y columnas
  • Esquema definido y rígido
  • Relaciones entre tablas mediante claves
  • Cumplen propiedades ACID (Atomicidad, Consistencia, Aislamiento, Durabilidad)
  • Ejemplos: MySQL, PostgreSQL, Oracle, SQL Server

Bases de Datos NoSQL (No Relacionales):

  • Estructuras flexibles: documentos, clave-valor, grafos, columnas
  • Escalabilidad horizontal
  • Ideales para big data y aplicaciones en tiempo real
  • Ejemplos: MongoDB, Redis, Cassandra, Neo4j

¿Cuándo usar cada una?

  • SQL: Cuando necesitas transacciones complejas, integridad de datos y estructura definida
  • NoSQL: Para grandes volúmenes de datos, escalabilidad y flexibilidad de esquema
Hardware

¿Qué es la CPU? El Cerebro del Ordenador

La Unidad Central de Procesamiento (CPU) es el componente principal de una computadora que ejecuta instrucciones de programas y procesa datos. Es considerada el "cerebro" del sistema.

Componentes Principales:

  • ALU (Unidad Aritmético-Lógica): Realiza operaciones matemáticas y lógicas
  • Unidad de Control: Coordina y dirige el funcionamiento del procesador
  • Registros: Almacenamiento temporal ultrarrápido
  • Cache: Memoria rápida para datos frecuentes

Características Importantes:

  • Frecuencia de reloj: Medida en GHz, indica cuántas operaciones puede realizar por segundo
  • Núcleos: CPUs modernas tienen múltiples núcleos (dual-core, quad-core, etc.)
  • Hilos de ejecución: Tecnología Hyper-Threading permite ejecutar múltiples procesos simultáneos
  • TDP: Potencia de diseño térmico, indica consumo energético y calor generado

Fabricantes Principales:

  • Intel: Core i3, i5, i7, i9
  • AMD: Ryzen 3, 5, 7, 9
  • ARM: Procesadores para móviles y dispositivos embebidos

Introducción a Linux

Linux es un sistema operativo de código abierto creado por Linus Torvalds en 1991. Es la base de la mayoría de servidores web, supercomputadoras y dispositivos embebidos del mundo.

Distribuciones Populares:

  • Ubuntu: Ideal para principiantes, gran comunidad
  • Debian: Estabilidad y robustez
  • Fedora: Innovación y tecnologías nuevas
  • Arch Linux: Para usuarios avanzados
  • CentOS/Rocky Linux: Entornos empresariales

Ventajas:

  • Gratuito y de código abierto
  • Alta seguridad y estabilidad
  • Personalización total
  • Gran soporte de comunidad

Redes

¿Cómo funciona un Router?

Un router (enrutador) es un dispositivo de red que dirige el tráfico de datos entre diferentes redes, permitiendo que los dispositivos se conecten a Internet y entre sí.

Funciones Principales:

  • Asignar direcciones IP (servidor DHCP)
  • Enrutar paquetes de datos
  • Proteger la red (firewall)
  • Proporcionar conectividad WiFi
  • Gestionar el tráfico de red (NAT)

Tipos de Routers:

  • Domésticos: Para hogares, combinan router y switch
  • Empresariales: Mayor capacidad y seguridad
  • Inalámbricos: Con WiFi integrado
  • De borde: Conectan redes internas con externas
Hardware

Memoria RAM: ¿Cuánta necesito?

La memoria RAM (Random Access Memory) es la memoria de acceso aleatorio donde el computador almacena temporalmente los datos que está utilizando en ese momento.

¿Cuánta RAM necesito?

  • 4 GB: Uso básico (navegación, ofimática ligera)
  • 8 GB: Uso estándar (multitarea, juegos ligeros)
  • 16 GB: Uso avanzado (gaming, edición de fotos)
  • 32 GB+: Profesional (edición de video, virtualización)

Tipos de RAM:

  • DDR4: Estándar actual, buen rendimiento
  • DDR5: Nueva generación, mayor velocidad
  • LPDDR: Para dispositivos móviles, bajo consumo

Bases de Datos

MongoDB: Bases de Datos NoSQL

MongoDB es una base de datos NoSQL orientada a documentos que almacena datos en formato BSON (similar a JSON). Es ideal para aplicaciones modernas y escalables.

Características:

  • Esquema flexible (sin estructura fija)
  • Alto rendimiento y escalabilidad horizontal
  • Consultas potentes y agregaciones
  • Índices para búsquedas rápidas
  • Replicación y sharding automático

¿Cuándo usar MongoDB?

  • Aplicaciones con datos no estructurados
  • Proyectos que requieren escalabilidad rápida
  • Desarrollo ágil con cambios frecuentes
  • Aplicaciones en tiempo real
Redes

Redes WiFi: Configuración y Seguridad

Las redes WiFi permiten la conexión inalámbrica de dispositivos a Internet mediante ondas de radio. Configurarlas correctamente es esencial para velocidad y seguridad.

Estándares WiFi:

  • WiFi 4 (802.11n): Hasta 600 Mbps
  • WiFi 5 (802.11ac): Hasta 3.5 Gbps
  • WiFi 6 (802.11ax): Mayor eficiencia y velocidad
  • WiFi 6E: Incluye banda de 6 GHz

Consejos de Seguridad:

  • Usar cifrado WPA3 o WPA2
  • Cambiar la contraseña por defecto
  • Ocultar el nombre de la red (SSID)
  • Actualizar el firmware del router
  • Filtrar por dirección MAC
Hardware

SSD vs HDD: ¿Cuál elegir?

Elegir entre un SSD (unidad de estado sólido) y un HDD (disco duro mecánico) depende de tus necesidades de velocidad, capacidad y presupuesto.

SSD (Unidad de Estado Sólido):

  • ✅ Mucho más rápido (hasta 10x)
  • ✅ Sin partes móviles, más resistente
  • ✅ Silencioso y menor consumo
  • ❌ Más caro por GB
  • ❌ Capacidad máxima menor

HDD (Disco Duro Mecánico):

  • ✅ Más económico por GB
  • ✅ Mayor capacidad disponible
  • ✅ Ideal para almacenamiento masivo
  • ❌ Más lento
  • ❌ Sensible a golpes y vibraciones

Recomendación:

Usa un SSD para el sistema operativo y programas principales, y un HDD para almacenamiento de archivos grandes.

Programación

Git y GitHub: Control de Versiones

Git es un sistema de control de versiones distribuido que permite rastrear cambios en el código. GitHub es una plataforma en la nube para alojar repositorios Git.

Comandos Git Esenciales:

  • git init - Inicializar repositorio
  • git add - Preparar cambios
  • git commit - Guardar cambios
  • git push - Subir al repositorio remoto
  • git pull - Descargar cambios
  • git branch - Gestionar ramas

Conceptos Clave:

  • Repositorio: Carpeta con historial de cambios
  • Commit: Instantánea de cambios
  • Branch: Línea de desarrollo paralela
  • Merge: Unir ramas
  • Pull Request: Proponer cambios en GitHub

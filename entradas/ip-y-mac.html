¿Qué son la IP y la MAC? Identificadores de Red

6 de noviembre de 2026 · Lectura de 3 min
← Volver a tutoriales

En el mundo de las redes informáticas, cada dispositivo necesita ser identificado de forma única para poder comunicarse con otros. Para ello existen dos tipos de direcciones fundamentales: la dirección IP y la dirección MAC. Aunque ambas sirven para identificar dispositivos, funcionan de manera muy diferente.

¿Qué es la Dirección MAC?

La dirección MAC (Media Access Control) es un identificador único y permanente asignado por el fabricante a cada tarjeta de red. Es como el "DNI físico" del dispositivo: no cambia nunca.

  • Formato: 6 pares de números hexadecimales separados por dos puntos
  • Ejemplo: 00:1A:2B:3C:4D:5E
  • Ámbito: Solo es útil dentro de la red local (LAN)
  • Permanente: Grabada en el hardware de fábrica

¿Qué es la Dirección IP?

La dirección IP (Internet Protocol) es un identificador lógico asignado a cada dispositivo conectado a una red. A diferencia de la MAC, la IP puede cambiar y depende de la red a la que estés conectado.

IPv4

  • Formato: 4 números de 0 a 255 separados por puntos
  • Ejemplo: 192.168.1.100
  • Total: 4.300 millones de direcciones (ya agotadas)

IPv6

  • Formato: 8 grupos de 4 caracteres hexadecimales
  • Ejemplo: 2001:0db8:85a3::8a2e:0370:7334
  • Total: 340 sextillones (prácticamente infinitas)

IP Pública vs IP Privada

  • IP Pública: La que te identifica en Internet. Asignada por tu proveedor (ISP).
  • IP Privada: La que usas dentro de tu red local (casa, oficina).

Diferencias entre IP y MAC

  • MAC: Física, permanente, ámbito local
  • IP: Lógica, puede cambiar, ámbito global
  • Analogía: La MAC es como tu DNI (no cambia), la IP es como tu dirección postal (puede cambiar si te mudas)

¿Cómo Ver tu IP y MAC?

  • Windows: Abre CMD y escribe ipconfig /all
  • Ubuntu/Linux: Abre la terminal y escribe ip a o ifconfig
  • Mac: Ve a Preferencias del Sistema → Red → Avanzado → Hardware

Sin direcciones IP y MAC, Internet y las redes locales no podrían funcionar. Juntas forman la base del modelo TCP/IP que hace posible Internet tal como lo conocemos.

Comandos Básicos de la Terminal en Ubuntu

6 de noviembre de 2026 · Lectura de 8 min
← Volver a tutoriales

La terminal (también llamada consola o línea de comandos) es una de las herramientas más potentes de Ubuntu. Aunque al principio puede parecer intimidante, dominar los comandos básicos te permitirá gestionar el sistema de forma mucho más rápida y eficiente que con la interfaz gráfica.

¿Cómo Abrir la Terminal?

Puedes abrir la terminal de varias formas:

  • Atajo de teclado: Ctrl + Alt + T
  • Buscando "Terminal" en el menú de aplicaciones
  • Clic derecho en el escritorio → "Abrir terminal"

Comandos de Navegación

  • pwd - Muestra la ruta de la carpeta actual
  • ls - Lista los archivos y carpetas del directorio actual
  • ls -la - Lista todo incluyendo archivos ocultos y permisos
  • cd carpeta - Entra en una carpeta
  • cd .. - Sube un nivel en la jerarquía
  • cd ~ - Vuelve a tu carpeta personal

Gestión de Archivos y Carpetas

  • mkdir nombre - Crea una nueva carpeta
  • touch archivo.txt - Crea un archivo vacío
  • cp origen destino - Copia archivos o carpetas
  • mv origen destino - Mueve o renombra archivos
  • rm archivo - Elimina un archivo
  • rm -r carpeta - Elimina una carpeta y su contenido

Gestión de Paquetes con APT

APT es el gestor de paquetes de Ubuntu. Estos son los comandos más usados:

  • sudo apt update - Actualiza la lista de paquetes disponibles
  • sudo apt upgrade - Instala las actualizaciones disponibles
  • sudo apt install nombre_paquete - Instala un programa
  • sudo apt remove nombre_paquete - Desinstala un programa
  • sudo apt autoremove - Limpia paquetes no necesarios

Permisos y Usuario

  • sudo comando - Ejecuta un comando como administrador (root)
  • whoami - Muestra el usuario actual
  • chmod permisos archivo - Cambia los permisos de un archivo
  • chown usuario archivo - Cambia el propietario de un archivo

Información del Sistema

  • uname -a - Muestra información del kernel
  • df -h - Espacio disponible en los discos
  • free -h - Memoria RAM disponible
  • top o htop - Procesos en ejecución
  • ip a - Muestra las direcciones IP de red

Trucos Útiles

  • clear o Ctrl + L - Limpia la pantalla
  • historial o flecha arriba - Muestra comandos anteriores
  • Tab - Autocompleta nombres de archivos y comandos
  • Ctrl + C - Cancela el comando en ejecución
  • man comando - Muestra el manual de ayuda de un comando

Con estos comandos básicos ya puedes desenvolverte con soltura en Ubuntu. La práctica es la clave: úsalos a diario y pronto te resultarán naturales.

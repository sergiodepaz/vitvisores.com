Cómo Instalar Ubuntu Paso a Paso

6 de noviembre de 2026 · Lectura de 4 min
← Volver a tutoriales

Instalar Ubuntu es un proceso sencillo que cualquiera puede realizar siguiendo esta guía. Aprenderás a crear un USB booteable, configurar la BIOS y realizar la instalación paso a paso, ya sea como único sistema o en dual boot junto a Windows.

Requisitos Previos

  • Un ordenador compatible (mínimo 4GB RAM, 25GB de espacio libre)
  • Un pendrive USB de al menos 4GB (se borrará todo su contenido)
  • Conexión a Internet
  • Copia de seguridad de tus datos importantes

Paso 1: Descargar Ubuntu

Ve a la página oficial ubuntu.com/download y descarga la última versión LTS (recomendada para la mayoría de usuarios). El archivo será una imagen ISO de aproximadamente 4-5 GB.

Paso 2: Crear un USB Booteable

Necesitas "quemar" la imagen ISO en el USB. Puedes usar:

  • Rufus (Windows): Ligero y muy popular
  • balenaEtcher (Windows/Mac/Linux): Interfaz muy sencilla
  • Startup Disk Creator (Ubuntu): Herramienta nativa

Paso 3: Configurar la BIOS/UEFI

Reinicia el ordenador y entra en la BIOS pulsando F2, F12, DEL o ESC (depende del fabricante):

  1. Desactiva Secure Boot (opcional pero recomendado)
  2. Cambia el orden de arranque para que el USB sea la primera opción
  3. Guarda los cambios y reinicia

Paso 4: Iniciar desde el USB

Al reiniciar verás el menú de Ubuntu con dos opciones:

  • Try Ubuntu: Probar el sistema sin instalarlo (modo Live)
  • Install Ubuntu: Iniciar el instalador directamente

Paso 5: El Instalador

El instalador te guiará por estos pasos:

  1. Idioma: Selecciona español
  2. Distribución del teclado: Elige tu idioma
  3. Actualizaciones: Marca "Instalar actualizaciones" y "Instalar software de terceros"
  4. Tipo de instalación: Elige entre borrar disco (Ubuntu único) o instalar junto a Windows (dual boot)
  5. Zona horaria y usuario: Configura tu cuenta

Paso 6: Reiniciar y Disfrutar

Cuando termine la instalación (15-30 minutos), reinicia el ordenador, retira el USB y ¡listo! Ya tienes Ubuntu instalado. Al arrancar verás el gestor GRUB donde podrás elegir entre Ubuntu y Windows si hiciste dual boot.

Primeros Pasos Tras la Instalación

  • Actualiza el sistema desde la terminal
  • Instala tus programas favoritos desde el Centro de Software
  • Configura las actualizaciones automáticas

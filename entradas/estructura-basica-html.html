HTML: Estructura Básica de una Página Web

6 de noviembre de 2026 · Lectura de 8 min
← Volver a tutoriales

HTML (HyperText Markup Language) es el lenguaje estándar para crear páginas web. Define la estructura y el contenido de una página mediante etiquetas que el navegador interpreta y muestra al usuario. En este tutorial aprenderás la estructura básica de un documento HTML5.

Estructura Fundamental de HTML5

Todo documento HTML sigue una estructura básica compuesta por varias etiquetas esenciales. Aquí tienes el esqueleto mínimo:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi Primera Página Web</title>
</head>
<body>
    <h1>¡Hola Mundo!</h1>
    <p>Esta es mi primera página web.</p>
</body>
</html>

Análisis de Cada Parte

1. DOCTYPE

<!DOCTYPE html> le indica al navegador que este documento es HTML5. Siempre va en la primera línea y no es una etiqueta HTML, sino una declaración.

2. Etiqueta html

<html lang="es"> es el elemento raíz que contiene todo el documento. El atributo lang="es" indica que el contenido está en español (importante para accesibilidad y SEO).

3. Head (Cabecera)

La etiqueta <head> contiene metadatos sobre el documento que no se muestran directamente en la página:

  • <meta charset="UTF-8"> - Define la codificación de caracteres (permite acentos, ñ, etc.)
  • <meta name="viewport"> - Hace que la página sea responsive en móviles
  • <title> - El título que aparece en la pestaña del navegador
  • <meta name="description"> - Descripción para SEO
  • <link> - Para enlazar archivos CSS externos

4. Body (Cuerpo)

La etiqueta <body> contiene todo el contenido visible de la página: textos, imágenes, enlaces, formularios, etc. Todo lo que el usuario ve está dentro de body.

Etiquetas Básicas Esenciales

  • <h1> a <h6> - Títulos (h1 es el más importante, h6 el menos)
  • <p> - Párrafos de texto
  • <a href=""> - Enlaces a otras páginas
  • <img src="" alt=""> - Imágenes
  • <ul> y <li> - Listas desordenadas
  • <ol> y <li> - Listas ordenadas
  • <div> - Contenedor genérico
  • <span> - Contenedor en línea

Ejemplo Completo

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi Web</title>
</head>
<body>
    <h1>Bienvenido a mi web</h1>
    <p>Este es un párrafo de ejemplo.</p>
    <a href="https://google.com">Ir a Google</a>
    <img src="foto.jpg" alt="Mi foto">
</body>
</html>

Buenas Prácticas

  • Siempre usa <!DOCTYPE html> al inicio
  • Define el idioma con lang
  • Usa un solo <h1> por página (para SEO)
  • Añade alt a todas las imágenes (accesibilidad)
  • Indentar el código para que sea legible
  • Cerrar siempre todas las etiquetas

Con esta estructura básica ya puedes crear tu primera página web. En los próximos tutoriales aprenderás a añadir estilos con CSS y interactividad con JavaScript.

HTML: Estructura Básica de una Página Web

6 de noviembre de 2026 · Lectura de 3 min
← Volver a tutoriales

HTML (HyperText Markup Language) es el lenguaje estándar para crear páginas web. Define la estructura y el contenido de una página mediante etiquetas que el navegador interpreta y muestra al usuario.

Estructura Fundamental de HTML5

Todo documento HTML sigue una estructura básica compuesta por varias etiquetas esenciales:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi Primera Página Web</title>
</head>
<body>
    <h1>¡Hola Mundo!</h1>
    <p>Esta es mi primera página web.</p>
</body>
</html>

Análisis de Cada Parte

1. DOCTYPE

<!DOCTYPE html> le indica al navegador que este documento es HTML5. Siempre va en la primera línea.

2. Etiqueta html

<html lang="es"> es el elemento raíz que contiene todo el documento. El atributo lang indica el idioma del contenido.

3. Head (Cabecera)

La etiqueta <head> contiene metadatos que no se muestran directamente en la página:

  • <meta charset="UTF-8"> - Define la codificación de caracteres
  • <meta name="viewport"> - Hace que la página sea responsive
  • <title> - El título que aparece en la pestaña del navegador

4. Body (Cuerpo)

La etiqueta <body> contiene todo el contenido visible de la página: textos, imágenes, enlaces, etc.

Etiquetas Básicas Esenciales

  • <h1> a <h6> - Títulos (h1 es el más importante)
  • <p> - Párrafos de texto
  • <a href=""> - Enlaces a otras páginas
  • <img src="" alt=""> - Imágenes
  • <ul> y <li> - Listas desordenadas
  • <div> - Contenedor genérico

Buenas Prácticas

  • Siempre usa <!DOCTYPE html> al inicio
  • Define el idioma con lang
  • Usa un solo <h1> por página (para SEO)
  • Añade alt a todas las imágenes (accesibilidad)
  • Cierra siempre todas las etiquetas

Con esta estructura básica ya puedes crear tu primera página web. En los próximos tutoriales aprenderás a añadir estilos con CSS y interactividad con JavaScript.
